# 评估用例（金标准）

> 用法：这些用例由 agent / 人工执行，结论记入 `reviews/` 或 PR 描述。
> CI 只跑机器可判定的部分（unittest + validate_pack）；风格类用例在发布前与
> 改动风格包内容时必须跑。

## Case A：鲁迅包模仿（narrative）

- **提示**：使用 stylepacks/luxun，写 200–300 字：第一人称，回乡在村口遇见儿时同伴，如今境遇悬殊。
- **期望特征清单**（命中 ≥ 5 视为通过）：
  1. 短句为主，偶以"然而/但/却"转折
  2. 至少一处矛盾修饰或模糊断语（"大约…的确…"类）
  3. 环境描写 ≤ 2 句且带象征义（不堆砌）
  4. 对话 ≤ 3 个来回，人物话语有身份感
  5. 结尾留余味（断语 / 反问 / 景语收束），不总结主题
  6. 无网络流行语、无欧化长定语、无滥用"的"字连串
- **机器验收**：`fp_check.py stylepacks/luxun <输出>` 通过

## Case B：朱自清包模仿（narrative）

- **提示**：使用 stylepacks/zhuziqing，写 200–300 字：夜色中的站台送别。
- **期望特征清单**（命中 ≥ 5 视为通过）：
  1. 叠词出现 ≥ 2 处（如"渐渐""微微"）
  2. 至少一个比喻，取材日常且清新（不当拉硬拽的博喻）
  3. 长句铺陈与短句收束交替
  4. 感官细节 ≥ 2 种（视觉/听觉/嗅觉…）
  5. 情感不直说，以景与动作外化
  6. 对话可有可无；出现则平实口语，不长篇大论
- **机器验收**：`fp_check.py stylepacks/zhuziqing <输出>` 通过

## Case C：指纹验收工具自证

- **操作**：对一段明显口语网文文本运行
  `fp_check.py stylepacks/luxun <文本>`，预期**不通过**（exit 1）且报告能指出偏差最大项。
- **判定**：工具能把"不像"翻译成可读的量化偏差。

## Case D：一致性检查召回

- **操作**：取 3 万字左右的样稿（或本项目 manuscript），人工植入 5 处错误：
  2 处人名错写、1 处时间线矛盾、1 处人物认知越界（说了不该知道的）、1 处伏笔丢失；
  运行 consistency-check 技能。
- **判定**：召回 ≥ 4/5；报告能区分"改稿"与"改 bible"。

## Case E：A/B 盲测（发布门槛）

- **操作**：style-calibrate 全流程，3–5 个中性提示。
- **判定**：胜率 ≥ 50% 可发 0.1.x；≥ 70% 视为包成熟。

## Case F：分层指纹与真迹包络（v0.2.8 语料扩充后更新）

- **数据**：downloads/corpus/luxun/（62 篇 20.4 万字，v0.2.8 扩充）+ zhuziqing（4 篇）
  + 生成结果/（AI 文本）；CI 无此目录时跳过
- **三类判定分开测**：
  1. **真迹必须过本层线**（auto 选层，扩充后抽验 7/7 ✅）：秋夜/风筝/雪→essay ✅；
     孔乙己/故乡/阿Q正传→narrative ✅；藤野先生→narrative ✅；背影→zhuziqing ✅
  2. **错作者拒绝（散文层能力随包络变宽而下降，如实记录）**：
     匆匆→luxun ❌（2/12）、荷塘→luxun ❌（1/13）仍被拒；
     **背影→luxun 现在 ✅ 通过**——26 篇真迹把 essay 层包络撑宽，朱自清中调散文
     落入包络内。**作者鉴别在此层交给跨包相对归因**（test_cross_validation_layered：
     luxun 侧 5/5 全对；zhuziqing 语料薄 2/4，合计 7/9 为当前诚实下限）
  3. **AI 文本落位**：文1/文2 需按新线复测（包络已变），趋势预期不变
- **已知限制（如实入档）**：
  - zhuziqing 语料仅 4 篇（源站当日不可达，扩充待补）：essay 层对自家作品归因
    余量极薄（两篇差距 < 0.2）；**补齐后应回到归因 ≥ 0.9 并收紧阈值**
  - luxun narrative 层留一线 **1.981（n=36）**、essay 层 **1.677（n=26）**——
    v0.2.3 时代的 18.99/不可标定两大限制均已解除
- **教训**：包络宽度与语料量正相关是真统计事实，不是缺陷；作者鉴别是
  **相对归因**（跨包距离比较）的任务，绝对包络只回答"是否落在该作者该文体的
  真迹范围内"——两层语义分开用

## Case G：语料扩充后重算（luxun 已完成，zhuziqing 待源）

- **已完成（v0.2.8）**：《野草》24 篇 +《朝花夕拾》13 篇 +《呐喊》/《彷徨》全部
  小说（含《阿Q正传》）共 62 篇 20.4 万字入库 → build_delta --layered 重建：
  essay 层 n=2→26（留一线从不可标定→1.677）、narrative 层 n=3→36（18.99→1.981）
- **判定结果**：Case F 第 1 类全部保持通过 ✅；narrative 层留一线显著收紧 ✅；
  essay 层留一线可标定 ✅——三条预期全部兑现
- **待补**：zhuziqing 补篇与新作者语料——源站当日不可达（维基文库/ccview/
  raw.githubusercontent 均超时，GitHub 无全集类仓库），登记表已更新备选源；
  用户侧提供 txt 为最快路径

## Case H：任意作者建档与验收（通用性金标准）

> 本项目不针对特定作者。Case F 是自带包的实例，本例是**任何作者语料**都必须
> 走通的同一流程；测试 TestGenericAuthorPipeline 已机械化（合成语料 CLI 全链路）。

- **操作**（对任意作者 X 的入库语料）：
  1. `fp_extract --genre-layers` 看分层预览 → 人工核对归属是否符合直觉
  2. `build_delta <语料> --pack stylepacks/<X包> --layered` 一键产出分层阈值 +
     分层 Delta 档案 + 层内留一及格线
  3. 核对：每层 samples 正确；n<3 的层 delta_profile 为 null、留一线置空
     （如实置空，禁止手拍数充数）
  4. `fp_check stylepacks/<X包> <语料某篇真迹>` → 该篇必须过本层线
  5. 换一位作者 Y 的一篇同文体真迹 → 必须不过 X 包（或至少 Delta 参考值显著高于
     X 自己的真迹）
  6. `validate_pack` + 真迹过线全绿后才升包版本
- **判定**：2–6 全绿；任何一步失败优先怀疑语料（脏数据 / 文体混编 / 来源错乱），
  回 style-analyze 1.5 体检，其次才怀疑机制

## Case I：思想层（v0.3，thought.md）

> 从"写得像"到"想得像"的第一步：蒸馏**思路的动作**（非思想的内容）。
> 制度底线：思想不进机械判定——motif advisory 永不改变 fp_check 退出码，
> 盲测是最终裁判。

- **机制**：thought.md 六节（选题地平线 / 立意动作 / 观察清单 / 意象系统 /
  价值姿态 / 禁区）+ motif 词表与 motif_stats（motif_count.py 脚本产出）。
  validate 查六节齐全与「motif 词表：」行（缺失 = 错误；无 thought.md 的包
  仅 1 条提示，向后兼容）；export 条件段并入「思想档案」节
- **判定纯净性**：`fp_check --thought` 输出 motif 密度对照但**退出码不受影响**
  （test_thought 锁定）；思想特征全部可 Goodhart（意象可堆砌），故只做参考
- **可溯源纪律**：立意动作与观察清单条目必须指认 exemplars 编号或语料篇目——
  luxun thought.md 全部条目已指认；不能溯源的条目删除
- **motif 剔除线校正**：1.5/千字是小语料防幻觉线；大语料按实际分布校正
  （luxun 20.8 万字 → 0.5/千字，防幻觉功能不变：≥0.5 即 ≥104 次出现）；
  "头"因"里头/石头"类方位词复合流量污染计数，手动剔除
- **应用侧**：style-apply 两级共创（立意确认 → 拍子表）+ **交付声明制**
  （声明本篇用了哪些立意动作与意象，引条目编号，用户可对照）；style-critique
  思想维度 + **贴标签检测**（motif 出现但与叙事无机——意象硬塞点名）；
  style-calibrate 思想盲测（同题材两问，判读问题 = "哪篇更像这个作者在思考"）
- **判定**：双包 thought.md 定稿（用户逐节校订通过）；泛用管线测试含思想步
  （TestGenericAuthorPipeline.test_thought_layer_cli）；zhuziqing 各节置信度
  逐节标注（语料仅 4 篇，回避 / 禁区为**弱禁用**）。**思想盲测首轮待跑**
  ——按 style-calibrate 协议，同题材两问 × 2 组
