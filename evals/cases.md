# 评估用例（金标准）

> 用法：这些用例由 agent / 人工执行，结论记入 `reviews/` 或 PR 描述。
> CI 只跑机器可判定的部分（unittest + validate_pack）；风格类用例在发布前与
> 改动风格包内容时必须跑。

## Case A：鲁迅包模仿（narrative）

- **提示**：使用 stylepacks/luxun，写 200–300 字：第一人称，回乡在村口遇见儿时同伴，如今境遇悬殊。
- **期望特征清单**（命中 ≥ 5 视为通过）：
  1. 短句为主，偶以"然而/但/却"转折
  2. 至少一处矛盾修饰或模糊断语（"大约…的确…"类）
  3. 环境描写 ≤ 2 句且带象征义（不堆砌）
  4. 对话 ≤ 3 个来回，人物话语有身份感
  5. 结尾留余味（断语 / 反问 / 景语收束），不总结主题
  6. 无网络流行语、无欧化长定语、无滥用"的"字连串
- **机器验收**：`fp_check.py stylepacks/luxun <输出>` 通过

## Case B：朱自清包模仿（narrative）

- **提示**：使用 stylepacks/zhuziqing，写 200–300 字：夜色中的站台送别。
- **期望特征清单**（命中 ≥ 5 视为通过）：
  1. 叠词出现 ≥ 2 处（如"渐渐""微微"）
  2. 至少一个比喻，取材日常且清新（不当拉硬拽的博喻）
  3. 长句铺陈与短句收束交替
  4. 感官细节 ≥ 2 种（视觉/听觉/嗅觉…）
  5. 情感不直说，以景与动作外化
  6. 对话可有可无；出现则平实口语，不长篇大论
- **机器验收**：`fp_check.py stylepacks/zhuziqing <输出>` 通过

## Case C：指纹验收工具自证

- **操作**：对一段明显口语网文文本运行
  `fp_check.py stylepacks/luxun <文本>`，预期**不通过**（exit 1）且报告能指出偏差最大项。
- **判定**：工具能把"不像"翻译成可读的量化偏差。

## Case D：一致性检查召回

- **操作**：取 3 万字左右的样稿（或本项目 manuscript），人工植入 5 处错误：
  2 处人名错写、1 处时间线矛盾、1 处人物认知越界（说了不该知道的）、1 处伏笔丢失；
  运行 consistency-check 技能。
- **判定**：召回 ≥ 4/5；报告能区分"改稿"与"改 bible"。

## Case E：A/B 盲测（发布门槛）

- **操作**：style-calibrate 全流程，3–5 个中性提示。
- **判定**：胜率 ≥ 50% 可发 0.1.x；≥ 70% 视为包成熟。

## Case F：分层指纹与真迹包络（v0.2.8 语料扩充后更新）

- **数据**：downloads/corpus/luxun/（62 篇 20.4 万字，v0.2.8 扩充）+ zhuziqing（4 篇）
  + 生成结果/（AI 文本）；CI 无此目录时跳过
- **三类判定分开测**：
  1. **真迹必须过本层线**（auto 选层，扩充后抽验 7/7 ✅）：秋夜/风筝/雪→essay ✅；
     孔乙己/故乡/阿Q正传→narrative ✅；藤野先生→narrative ✅；背影→zhuziqing ✅
  2. **错作者拒绝（散文层能力随包络变宽而下降，如实记录）**：
     匆匆→luxun ❌（2/12）、荷塘→luxun ❌（1/13）仍被拒；
     **背影→luxun 现在 ✅ 通过**——26 篇真迹把 essay 层包络撑宽，朱自清中调散文
     落入包络内。**作者鉴别在此层交给跨包相对归因**（test_cross_validation_layered：
     luxun 侧 5/5 全对；zhuziqing 语料薄 2/4，合计 7/9 为当前诚实下限）
  3. **AI 文本落位**：文1/文2 需按新线复测（包络已变），趋势预期不变
- **已知限制（如实入档）**：
  - zhuziqing 语料仅 4 篇（源站当日不可达，扩充待补）：essay 层对自家作品归因
    余量极薄（两篇差距 < 0.2）；**补齐后应回到归因 ≥ 0.9 并收紧阈值**
  - luxun narrative 层留一线 **1.981（n=36）**、essay 层 **1.677（n=26）**——
    v0.2.3 时代的 18.99/不可标定两大限制均已解除
- **教训**：包络宽度与语料量正相关是真统计事实，不是缺陷；作者鉴别是
  **相对归因**（跨包距离比较）的任务，绝对包络只回答"是否落在该作者该文体的
  真迹范围内"——两层语义分开用

## Case H：任意作者建档与验收（通用性金标准）

> 本项目不针对特定作者。Case F 是自带包的实例，本例是**任何作者语料**都必须
> 走通的同一流程；测试 TestGenericAuthorPipeline 已机械化（合成语料 CLI 全链路）。

- **操作**（对任意作者 X 的入库语料）：
  1. `fp_extract --genre-layers` 看分层预览 → 人工核对归属是否符合直觉
  2. `build_delta <语料> --pack stylepacks/<X包> --layered` 一键产出分层阈值 +
     分层 Delta 档案 + 层内留一及格线
  3. 核对：每层 samples 正确；n<3 的层 delta_profile 为 null、留一线置空
     （如实置空，禁止手拍数充数）
  4. `fp_check stylepacks/<X包> <语料某篇真迹>` → 该篇必须过本层线
  5. 换一位作者 Y 的一篇同文体真迹 → 必须不过 X 包（或至少 Delta 参考值显著高于
     X 自己的真迹）
  6. `validate_pack` + 真迹过线全绿后才升包版本
- **判定**：2–6 全绿；任何一步失败优先怀疑语料（脏数据 / 文体混编 / 来源错乱），
  回 style-analyze 1.5 体检，其次才怀疑机制

## Case I：思想层（v0.3，thought.md）

> 从"写得像"到"想得像"的第一步：蒸馏**思路的动作**（非思想的内容）。
> 制度底线：思想不进机械判定——motif advisory 永不改变 fp_check 退出码，
> 盲测是最终裁判。

- **机制**：thought.md 六节（选题地平线 / 立意动作 / 观察清单 / 意象系统 /
  价值姿态 / 禁区）+ motif 词表与 motif_stats（motif_count.py 脚本产出）。
  validate 查六节齐全与「motif 词表：」行（缺失 = 错误；无 thought.md 的包
  仅 1 条提示，向后兼容）；export 条件段并入「思想档案」节
- **判定纯净性**：`fp_check --thought` 输出 motif 密度对照但**退出码不受影响**
  （test_thought 锁定）；思想特征全部可 Goodhart（意象可堆砌），故只做参考
- **可溯源纪律**：立意动作与观察清单条目必须指认 exemplars 编号或语料篇目——
  luxun thought.md 全部条目已指认；不能溯源的条目删除
- **motif 剔除线校正**：1.5/千字是小语料防幻觉线；大语料按实际分布校正
  （luxun 20.8 万字 → 0.5/千字，防幻觉功能不变：≥0.5 即 ≥104 次出现）；
  "头"因"里头/石头"类方位词复合流量污染计数，手动剔除
- **应用侧**：style-apply 两级共创（立意确认 → 拍子表）+ **交付声明制**
  （声明本篇用了哪些立意动作与意象，引条目编号，用户可对照）；style-critique
  思想维度 + **贴标签检测**（motif 出现但与叙事无机——意象硬塞点名）；
  style-calibrate 思想盲测（同题材两问，判读问题 = "哪篇更像这个作者在思考"）
- **判定**：双包 thought.md 定稿（用户逐节校订通过）；泛用管线测试含思想步
  （TestGenericAuthorPipeline.test_thought_layer_cli）；zhuziqing 各节置信度
  逐节标注（语料仅 4 篇，回避 / 禁区为**弱禁用**）
- **思想盲测首轮（2026-09-30，已跑）**：判官 = 4 个独立子代理（不读风格包，
  防循环论证），写手 = 8 个独立子代理（带包臂全六件装载 + fp_check 自检，
  无包臂纯先验）；2 题 × 自由/约束立意 4 回合——**带包臂 3/4**（全部高置信度）。
  R3 失利：带包段给人物立了抒情碑收尾，恰违反 thought.md 禁区"结尾不给
  安慰"——思想纪律失守只能被盲测抓住（无机械门，按设计），教训落账
  calibration.json；实跑工作流应启用 style-critique 贴标签检测。明细见
  evals/calibration.json `thought_blind_v030`
- **思想盲测续跑（2026-10-05，v0.4.0）**：4 回合（luxun 2 + zhuziqing 2，
  后者用 thought.md r2）——**带包 3/4，累计 6/8**。zhuziqing r2 两轮全胜：
  判官获胜理由正是 r2 重蒸馏出的判据（亲人以劳作现身 / 情感不点破 / 物化
  收束）；两场失利同因 = 带包臂**表层借句**（整句搬运《孔乙己》结尾）被
  点名——收尾检查与贴标签检测的实跑价值再证。明细入 calibration.json
  `thought_blind_v040`
- **三仪交叉终审（2026-10-05，v0.4.1）**：用户授权子代理终审，三套独立测试
  + r2 对抗审查。**luxun 三仪俱证**（自由辨认带包 6/6 首选鲁迅 vs 无包 3/6；
  判据合规带包 6×18/18 vs 无包均值 13.67；乱真归属带包 6/6 同手 vs 无包 2/6）
  ——档案的工程价值 = 方差为零（每篇都保持在判据内）。**zhuziqing 分歧如实
  记录**（辨认反向、归属混合、合规无区分——评分器稀有判据缺陷）。r2 对抗
  终审"有条件通过"，3 条改判已采纳为 thought.md **r3**（社会冲突回条件项/
  虚构禁写限散文体/居高临下改禁无自省/议论三选一/反讽三分/体罚拆分/
  低频条目标注）；文I"像而越轨"案例入档。明细见 calibration.json
  `final_verdict_v040`

## Case J：调子分区统计真实性（R1 判据，负结果）

> 预注册判据（计划书 §3 r2）：层间归因率显著高于置换零假设（p ≤ 0.05），
> 达线分区才写入指纹。仪器：splib attribution / permutation（全局基准，
> 固定种子 20260930）。**结论：全轴不显著——指纹分区不落地，六分区全部
> 退回仅路由（R0 示范段路由保留）。**

- **仪器验证（先于判读）**：阳性对照 = 文体标签（已知真实分层）——度量空间
  归因 0.871 / 零假设 0.505 / **p=0.0** ✅；阴性对照 = 随机标签——p=0.51 ✅。
  字频 Delta 空间连文体都归因不动（p=0.64）——结构信号在度量空间，不在字频
- **正式结果（度量空间，全局基准，n=500–1000）**：情感轴 k=3 归因 0.370 /
  p=0.336；节奏轴 k=3 归因 0.529 / p=0.278；全部 k=2 合并变体 p=0.24–0.72。
  字频空间同样全不显著
- **基准纪律（本例最重要的方法论产出）**：逐轴自建 z-score 基准曾给出
  p=0.01 / p=0.0 的"显著"——换全局基准后消失。判定为**基准伪影**，以预注册
  的全局基准为准；教训入档：显著性检验的基准选择必须先于看数固定
- **分层明细（条件值，不改变裁决）**：沉郁哲思 0.818、对话场 0.850 看似强，
  但轴级不显著 + 多重比较——对话场的信号与既有 narrative 层的对话密度同源
  （文体阳性对照 0.871 即此信号），无新增信息；白描/抒情在度量上不可分
  （差在语义层）；温情/讽刺/抒情归因接近或低于随机
- **含义**：① 调子在表层统计空间（字频 + 12 维句法度量）没有超出分组规模
  伪影的信号——计划书 §1"情感=软轴"的理论预测被数据证实并加强；② R0 的
  价值定位由此更清晰：调子路由是**语义层**的上下文选择，统计层不背书也不
  需要背书；③ R2（跨作者区间）前置条件更严——同作者内部调子尚且不可分，
  跨作者区间包的统计前提更弱；④ 语料扩充后可重跑 `registers_dryrun.py`
  复核，达线再翻转标定状态（registers.md 已留槽位）

## Case K：散文层与思想层同步重蒸馏（profile r2）＋借句初筛上线

> 遗留闭环（总账 2.6）：thought r2/r3 推翻"对话极少"、改议论条件项后，
> 4 篇时代的散文层（profile/lexicon/limits/card/exemplars）与思想层打架。
> 语料 10 篇逐条重裁决，每条改动指认篇目；指纹不动（已 n=10）。

- **对话按关系分层**（推翻"散文中对话极少"）：亲人极简指令式（《背影》
  5 句无一字抒情）/童语成串稚拙（《儿女》饭桌）/对答窘态省略号
  （《秦淮河》三连拒）/市井语作世情注脚（《南京》车夫语）——四分法
  直接进入生成指导表与 exemplars
- **议论改三通道条件项**（对齐 thought r3）：亲历引出/借引语承载/落回自身，
  设问自答合法（《匆匆》）；内容层禁区不重复，指回 thought.md（职责分工）
- **结构补三构型**：纪游列叙式、忆人三叠式、自省忏悔式；情感谱扩
  （忏悔自贬/幻灭怅惘/实事托住的直抒/愤怒峰值锚实物落自照）
- **exemplars 8→12**：童语成串/对答窘态/幻灭收束/直抒收束四条新范例，
  使新能力在生成端有路由目标（否则场景映射不到手法）
- **借句初筛（borrow_check.py）**：草稿 vs 范例引文 ≥12 字逐字重叠检测
  （规范化后滑窗，命中延展至最大重叠）——盲测两败同因"整句搬运"有了
  机器初筛层；**初筛不是终判**，化用/骨架雷同仍靠盲测与人工判读兜底；
  exit 0/1 可作可选门，advisory 纪律不变
- **迷你辨认盲测（calibration.json `recognition_v043`）**：2 回合，
  辨认 2/2、乱真归属 2/2（置信：高/中偏高）——r3 后 zhuziqing 辨认分歧
  拿到有利数据点；n=2 只记趋势，判官同源偏差仍靠人工判读包度量
- 教训：**包内各层是同一具尸体上的器官**——语料扩充或某层修订后，其余层
  必须同步重裁决，否则档案自相矛盾且生成端无范例可路由
