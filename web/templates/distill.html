蒸馏 · 新作者风格包

状态机：语料入库 → 指纹与体检 → 采样精读 → 草案生成 → 逐节校订 → 定稿。 每个操作旁给出等价 CLI——网页与命令行完全等价（插件红线）；草稿包（status: draft） 不出现在创作页与公开站点，定稿后才可见。

① 语料入库

已有语料？下方直接选语料集即可，无需重复入库。

python scripts/ingest.py --input <文件> --out downloads/corpus/<作者> --work <作品> [--source-url URL] [--no-strip-ads] [--unwrap]

② 指纹与体检

python scripts/fp_extract.py downloads/corpus/<语料集> --json stylepacks/<包>/fp_extract.json python scripts/build_delta.py downloads/corpus/<语料集> --pack stylepacks/<包> --layered [--exclude 离群文件...]

③ 采样精读（阶段 B · 模型调用）

按当前语料集与体检剔除名单选样。

精读结果（analysis.json，工作数据——可编辑，草案阶段将引用；改完点保存）：

技能路径：style-analyze（分层采样精读，六问题+思想四问——网页端以写作路由完成同一流程；每判断须溯源到篇目）

④ 草案生成（阶段 C · 模型调用）

依赖阶段 B 的 analysis.json。
技能路径：style-analyze 步 3（九章草案 → motif_count.py <语料> --pack <包> --write）

⑤ 逐节校订（人工，不可跳过）

重点核对：生成指导映射表、禁用清单、limits、thought 溯源性。

⑤.5 盲测验收（v0.8.0 · 模型调用，推荐定稿前跑）

同题"带包/不带包"各生成一段、打乱甲乙——你来盲选哪段像作者；胜率入 calibration。
等价技能：style-calibrate（A/B 盲测校准，胜率反推档案薄弱维度）；题库 tests/blind-prompts.md 可在步⑤编辑器校订
