# 鲁迅文风档案（profile）

## 三百字精华

鲁迅文风：冷峻白话，短句为主，常以「然而 / 但 / 却 / 便」句内转折；估测与意外类虚词是签名——「大约、似乎、仿佛、未必、竟、终于、倒、横竖」。叙事以第一人称回忆视角为主，叙述者是归乡的知识者，冷静旁观，哀其不幸怒其不争。讽刺靠细节并置，不靠形容词；比喻白描精准（「正像一个画图仪器里细脚伶仃的圆规」）。对话极简，人物话语高度个性化。情绪一律外化于景（苍黄的天、严冬的肃杀）。开头从实景或回忆切入；结尾以景语或断语收束留余味（「大约孔乙己的确死了」）。标志手法：刻意重复（两株枣树）、矛盾断语、省略号呼告（「救救孩子……」）。

## 叙事视角与人称

- 以第一人称回忆视角为主（《故乡》《孔乙己》《祝福》中的「我」）：亲历者 + 冷眼旁观者
- 叙述姿态：克制的悲悯。不站出来评判人物，评判藏在选材与并置里
- 偶用第三人称限知（《药》《白光》），镜头贴着人物但拒绝进入内心独白
- 时间常态是「回望」：开篇从眼前实景或旧忆切入，今昔对照是骨架

## 句式与节奏

- 短句为主，中位句长明显低于一般白话；节奏靠顿挫不靠铺陈
- 转折词高频：然而 / 但 / 却 / 倒 / 便——常在句内完成一次「松一下再收紧」
- 估测类虚词签名：大约 / 似乎 / 仿佛 / 未必 / 竟 / 终于（不确定语气本身是态度）
- 标志句式模板：
  - 矛盾断语式：「大约……的确……」（估测与确证相抵，冷漠口吻下藏余痛）
  - 重复凝视式：「一株是枣树，还有一株也是枣树」（视线移动的荒凉感）
  - 「便」字连动式：动作一句接一句，不加连接词
  - 「罢」字句尾：揣测与无奈（「或者也未必如此罢」）
- 标点指纹：省略号承担「说不尽」；破折号承担转折与补叙；感叹号极少

## 词汇与用典

- 白话奠基期语言：平实底子上留有文言残留——俨然、惘然、踌躇、委实、萧索、世故、素不相识
- 动词精准有力度：「横着几个萧索的荒村」「挂出一条火炬形的牌子」——选动词不选形容词
- 白描式比喻：取材日常器物与身体（圆规、芦柴棒式的小手），拒绝华丽意象
- 四字格多用书面语组合而非成语堆砌

## 对话风格

- 极简：对话常一句话，最多三四个来回；对话之间用叙述动作间隔
- 人物话语高度个性化，靠语言本身立人设：
  - 迂腐文白：「不多不多！多乎哉？不多也。」
  - 口头禅式重复：「我真傻，真的，」
  - 位置语与称呼讲究（「老爷！」的一声隔膜）
- 对话引导词常用「道」，不用「说」的变体花样
- 潜台词不点破：人物说的与心里想的之间的落差留给读者

## 场景与结构

- 转场干净：空行或一句景语切换，绝不写「与此同时」式说明文转场
- 开篇两种惯例：眼前实景定调（《故乡》的深冬船舱）／回忆引线（《孔乙己》的酒店格局）
- 中段靠细节累积推进，事件密度低但每事必有用
- 结尾三型：景语收束、断语收束（矛盾断语为最）、呼告省略号收束——一律留余味，不总结主题

## 情感与氛围

- 情绪一律外化：写「苍黄的天」「严冬的肃杀」，不写「我很难过」
- 冷峻中的温度：叙述越克制，悲悯越重；哀其不幸怒其不争是总姿态
- 讽刺内敛：让事实并置说话（讲学问的与卖馒头的同框），不加评语
- 氛围词域：阴冷、昏暗、肃杀、寂静——明亮场景也要留一笔暗色

## 禁用清单

- 网络流行语与外来语（内卷、躺平、OK、DNA……）
- 欧化长定语（「一个穿着红色毛衣的正在微笑的女孩」式）与连串「的」
- 直白情绪命名：「我很悲伤」「他感到愤怒」（一律外化）
- 长段心理独白
- 感叹号连用、省略号滥用（除呼告与「说不尽」处）
- 成语堆砌与华丽意象铺陈
