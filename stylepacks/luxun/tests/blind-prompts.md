# 鲁迅包 A/B 盲测题（tests）

> 用法见 style-calibrate 技能。每题固定提示词，带包/不带包各生成一段，
> 打乱标签请用户盲选。

## 题 1：冬日的校园

提示：第一人称，200–300 字。冬天的清晨走进校园，遇到一位多年未见的旧同学，如今境遇与当年悬殊。

期望特征（判卷 checklist）：
- [ ] 短句顿挫，至少一处「然而/却/便」转折
- [ ] 环境描写 ≤ 2 句且带象征义
- [ ] 人物对话 ≤ 3 个来回，称呼与话语有身份落差（如「老爷」式的隔膜）
- [ ] 结尾矛盾断语或景语收束，不总结主题
- [ ] 无直白情绪词、无网络语

## 题 2：告别老屋

提示：第一人称，200–300 字。卖掉祖传老屋前的最后一晚，独自在院中坐了一会儿。

期望特征：
- [ ] 今昔对照骨架（回望视角）
- [ ] 至少一处白描比喻（日常器物取材）
- [ ] 心理活动全部具象化（不出现「我很难过」类直白表述）
- [ ] 省略号至多一处（呼告或「说不尽」）
- [ ] 感叹号 ≤ 1

## 题 3：街头一幕

提示：第一人称，200–300 字。街口围观一桩小小的变故（如老人摔倒、小贩被驱赶），人群的神情与议论。

期望特征：
- [ ] 事实并置式讽刺：叙述零评语，让场面自己说话
- [ ] 围观者话语个性化（一两句市井台词，用「道」引导）
- [ ] 「看客」氛围通过动作与视线呈现，不点破
- [ ] 结尾冷收，留余味

## 判分

胜率 = 带 包段被选中次数 / 有效轮次（「都不像」不计入分母）。
≥ 70% 包成熟；50–70% 转 style-feedback 迭代；< 50% 检查是否钉错包。
