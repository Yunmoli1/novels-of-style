# 鲁迅词汇与句式（lexicon）

## 标志虚词（写作时主动布置，密度参考指纹）

- 估测 / 意外类：**大约、似乎、仿佛、未必、竟、终于、倒、也许、或许**
- 转折类：**然而、但、却、可是**（「然而」是最高频的书面转折）
- 顺承 / 完成：**便、就、了**（「便」字连动是节奏签名）
- 语气收尾：**罢**（「或者也未必如此罢」——揣测与无奈）

## 文言残留词（适度点缀，营造白话奠基期语感）

俨然、惘然、踌躇、委实、萧索、世故、素不相识、无关大体、横竖、究竟、大抵、略略、确凿、抱怨、恍惚

## 标志句式模板

1. 矛盾断语式：「大约……的确……」
2. 重复凝视式：「一株是 X，还有一株也是 X」
3. 「便」字连动式：「……便……便……」动作流水，不加连接词
4. 「罢」字揣测句：「……罢」
5. 「没有一些 + 名词」的否定强调：「没有一些活气」
6. 对话引导用「道」：「他道：……」

## 高频字（来自语料统计，供语感校准）

见 fingerprint.json `reference.top_chars` 与 `reference.fourgram_top`——
建档时从真实语料提取，用包者不必背诵，写作后以 fp_check 校准。

## 禁用清单（出现即不合格）

- 网络流行语：内卷、躺平、yyds、绝绝子、破防、硬核……
- 现代外来语：OK、DNA、KPI……及一切字母词
- 欧化长定语与连串「的」（一个名词前定语 ≤ 2 层）
- 直白情绪命名：「我很悲伤 / 他感到愤怒」（一律改外化）
- 长段心理独白（心理一律具象化处理）
- 感叹号连用；省略号只许用于呼告与「说不尽」处
- 成语堆砌、华丽意象铺陈（"宛如仙境""美得窒息"类一律禁）
