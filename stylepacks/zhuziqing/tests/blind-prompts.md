# 朱自清包 A/B 盲测题（tests）

> 用法见 style-calibrate 技能。每题固定提示词，带包/不带包各生成一段，
> 打乱标签请用户盲选。

## 题 1：夜色中的站台

提示：第一人称，200–300 字。深夜的火车站台送别一位长辈。

期望特征：
- [ ] 动作白描写长辈（衣着颜色、具体动作），零情感词
- [ ] 若有对话，朴素指令式（「……去。就在此地……」式）
- [ ] 感官分层 ≥ 2 种
- [ ] 叠词 ≥ 2 处且不堆在动词上
- [ ] 收束于一个短句或自嘲反转

## 题 2：雨后的院子

提示：第一人称，200–300 字。夏日雨后走进院子，草与花都带着水。

期望特征：
- [ ] 三联博喻至少一处（像……，像……，像……）
- [ ] 拟人 + 叠词后置句式（偷偷地……，嫩嫩的，绿绿的）
- [ ] 感官推进有层次（视→听→嗅任一顺序）
- [ ] 情感外化，无「我很开心」类直白表述
- [ ] 无宏大抽象词、无网络语

## 题 3：旧书桌前

提示：第一人称，200–300 字。整理旧物翻出儿时的书桌，想起当年不肯用功的自己。

期望特征：
- [ ] 排比或设问推进回忆
- [ ] 「淡淡」情调：哀愁不过量，单次情绪峰值
- [ ] 具体物件承载记忆（颜色、质地写到细节）
- [ ] 反语收束（「那时真是太……了」式）或问句收束
- [ ] 无长篇议论段

## 判分

胜率 = 带包段被选中次数 / 有效轮次（「都不像」不计入分母）。
≥ 70% 包成熟；50–70% 转 style-feedback 迭代；< 50% 检查是否钉错包。
