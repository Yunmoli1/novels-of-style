## 选题地平线

**写**（置信中——四篇皆抒情散文）：身边一景一事的片段——送站（《背影》）、一夜散步（《荷塘月色》）、季节（《春》）、时间之叹（《匆匆》）；家变侧写（"祸不单行的日子"，《背影》）；自我心境波动（"心里颇不宁静"，《荷塘月色》）。

**回避**（弱结论，选样偏差，禁当硬规则）：虚构人物与情节、社会冲突场面、讽刺笔法、直露议论。

## 立意动作

1. **小物承大情**：单一画面扛全部情感——父亲的背影（《背影》）。置信中：四篇仅此一篇完整演示
2. **心境开场、景作出口**：由"心里颇不宁静"引出夜游荷塘（《荷塘月色》）
3. **抽象时间具象化**：日子"从水盆里过去""从饭碗里过去"（《匆匆》）
4. **递进三喻收束**：春天"像刚落地的娃娃""像小姑娘""像健壮的青年"（《春》）

## 观察清单

- **动作分解**：攀、缩、"向左微倾"——父亲爬月台（《背影》）
- **衣饰与颜色**：黑布小帽、黑布大马褂、深青布棉袍（《背影》）
- **光影明暗层次**：斑驳的黑影与稀疏的倩影、塘上的月色（《荷塘月色》）
- **声音与气味**：蜂儿"嗡嗡地闹着"、花"缕缕清香"（《春》）；蝉声蛙声（《荷塘月色》）
- **居家细碎**：妻"拍着闰儿"哼着眠歌（《荷塘月色》）

## 意象系统

核心意象族：**月与光影**（满月 / 月光 / 黑影 / 倩影）；**水与流动**（流水 / 水盆 / 时间的流）；**草木花**（桃杏梨 / 杨柳 / 叶子）；**轻烟薄雾**（"如轻烟""薄薄的青雾"）。

motif 词表：日子、月、花、树、光、叶、影、风、父亲、水

## 价值姿态

1. **永远第一人称"我"，只写我看见的，不写他人内心**——《背影》全程写父亲外观
2. **情感降一档：峰值处用自嘲或侧笔，不说破**——"那时真是太聪明了"（《背影》）
3. **对读者用"你"呼告、设问邀请共思，不训导**——"聪明的，你告诉我"（《匆匆》）
4. **结尾落回具体物或现实，不做总结升华**——背影混入人群（《背影》）；"推门进去……妻已睡熟好久了"（《荷塘月色》）
5. **怅惘留白**——"热闹是它们的，我什么也没有"（《荷塘月色》）

## 禁区

（弱禁用——四篇选样推断，补语料后修订；写了也不像、宁可平实）

- 鲁迅式反讽与刻薄语——四篇全无，写了必串味
- 暴力血腥直写——丧事亦全用侧笔（《背影》）
- 抽象概念思辨长段——哲思必须全部具象化才成立（《匆匆》的写法）
- 多人对话与强冲突情节——对话仅一二句家常
- 欧化长句堆叠——句短、逗号密、口语化（"赶趟儿"）
- 情感爆发式抒情——峰值仍锚在实物意象上
