# corpus-ingest：语料清洗入库

## 用法

对每个语料文件运行（多文件逐一运行，每个文件一个 `--work`）：

```bash
python scripts/ingest.py --input <原始.txt> --out <项目>/corpus/<作者或来源标识> \
  --work <作品名> --source-url <URL，如有> --source-date <抓取日期，如有> --notes <备注>
```

脚本自动完成：编码探测（BOM / UTF-8 / GB18030 / Big5）→ 去广告行 → 章节切分
（`第X章/回/节`、`Chapter N`、`序章/楔子/尾声` 等标题）→ 按章写
`chapters/NNN-标题.md` → 写 `provenance.json` 与 `stats.json`（逐章统计缓存）。

## 操作要点

1. **粘贴文本**：用户直接粘贴的长文本先落盘为 txt（UTF-8）再走脚本，不要手工分段
2. **广告误伤**：若正文含合法 URL 或"PS:"等内容被误删，加 `--no-strip-ads` 重跑并人工核对
3. **无章节标题的散文**：整篇作为单章入库，属正常现象
4. **增量**：新增一章只需对新文件再跑一次（`--work` 用同一作品名会重建该作品，
   新章节请用新文件 + 新 `--work`，或手动追加章节文件后删除 stats.json 让下次重新生成）
5. **完成后汇报**：作品名、章节数、总字符数、原编码、去广告行数

## 纪律

- `provenance.json` 必须如实填写来源；联网抓取的语料记录 URL 与日期
- 语料目录提醒用户加入 `.gitignore`；**受版权保护的全文永不进入 git 仓库**
- 入库产物只服务于统计分析，风格包只收录统计结果与短引，不收录全文
