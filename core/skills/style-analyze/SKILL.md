# style-analyze：风格蒸馏

前置：语料已由 `corpus-ingest` 入库（存在 `corpus/<来源>/<作品>/chapters/` 与 `stats.json`）。

## 流程

### 1. 量化统计（脚本先行，不浪费模型 token）
```bash
python scripts/fp_extract.py <项目>/corpus/<来源> --json /tmp/fp_<作者>.json
```
记录：句长 P25/P50/P75、段落 P50、对话段占比、引号内容占比、标点/千字、
叠词率、高频字、高频四字组（若装有 jieba 还有词频）。这些数据同时反哺 lexicon。
统计口径（如实转告用户，勿夸大覆盖面）：叠词率仅统计相邻叠字（AA 型，如"渐渐"），
不含 ABA/ABAB；四字组为非重叠滑窗计数。

### 1.5 语料体检（脏语料防护，结论进档案元数据）

- **多来源交叉验证**：关键作品尽量取两个独立来源比对，不一致段落人工裁决
  （哪个是作者原文、哪个是转载改写）
- **离群章节警告**：某章对话比 / 句长显著偏离全书分布（stats.json 可直接看出），
  提示可能混入广告残留、防爬改写或他人代笔——剔除后再统计，别让脏数据进指纹
- **如实落账**：以上结论写进 `pack.json.corpus.confidence` 与 `provenance.notes`
  （来源质量、笔误情况、剔除项），供使用者判断档案可信度

### 2. 分层采样精读（控制成本：读样本，不通读全书）
从 `stats.json` 选取章节：开头 / 中段 / 结尾各 1–2 章；
对话密集章与叙述密集章各 1 章（按各章 `dialogue_para_ratio` 挑）。
精读时回答：叙事视角与人称、句子如何制造节奏、对话如何区分人物、
场景如何转换、情绪如何外化、标志性手法清单。

**思想四问（v0.3，同一次精读只加问题不加减读）**：① 作者**选择写**什么、
**拒绝写**什么（对比已入库篇目的题材分布）；② 从题材到角度用了什么**招式**
（逐篇指认，汇总为立意动作表）；③ 作者的眼睛反复落在**哪几类细节**上；
④ 反复出现的**意象族**是什么（提案 motif 词表：文本中**字面反复出现**的
词/单字，10–30 词、建议 15 词起步）。

### 2.1 成本纪律（硬性，不可省略）

- **开跑预告 + 落账**：动手前向用户预告本次读取规模（约多少字 / 几个文件 / 是否派子代理），
  明显超出预期时先确认；完成后记一笔账：
  `python scripts/cost.py log --skill style-analyze --chars <字数> --files <文件数> --project <项目>`
- **并行批量读**：选中的全部章节放在**同一轮并行工具调用**中一次读完，
  禁止逐个串行读——agent 每次调用都会重发全部会话历史，串行读 N 章的
  实际开销约为并行方式的数倍
- **超大语料 map-reduce**：语料总量 > 100k 字时不直接读，派 3–5 个子代理，
  每个子代理只读自己分到的那一块，各回一份 ≤ 800 字的风格观察摘要
  （视角 / 节奏 / 对话 / 场景 / 标志性手法五项），主会话只读摘要做汇总蒸馏
- **摘要不是交付物**：精读只回答上面六个问题，严禁全文复述或大段摘抄进会话；
  范例引文在写 exemplars.md 时再从原文件定点取，不提前搬运


### 3. 产出风格包草案（目录 `stylepacks/<包名>/`）
- `profile.md`：严格按九章骨架（三百字精华 / 叙事视角与人称 / 句式与节奏 /
  词汇与用典 / 对话风格 / 场景与结构 / 情感与氛围 / 生成指导 / 禁用清单）。
  生成指导必须写成"遇 X 场景 → 用 Y 手法 → 参考范例 N"的映射表
- `card.md`：≤400 字精华，从 profile 提炼
- `thought.md`（可选，v0.3 思想层）：按六节骨架写（选题地平线 / 立意动作 /
  观察清单 / 意象系统 / 价值姿态 / 禁区）。立意动作与观察清单条目必须能
  **指认到 exemplars 编号或语料篇目**——不能溯源的条目删除；价值姿态落成
  **可执行指令**（如"哀其不幸怒其不争"→"叙述者后退半步，让事实并置，
  禁直接评判"）。motif 词表提案后脚本验证（防幻觉意象）：
  ```bash
  python scripts/motif_count.py <项目>/corpus/<来源> --pack stylepacks/<包名> --write
  ```
  频率 < 1.5/千字的 motif 自动剔除并写回 motif_stats 节——提案是模型的，
  数字是脚本的
- `exemplars.md`：**短、多、带批注**。每条 = `### 特征标签` + `> 引文`（≤200 字）+
  批注（演示了什么、何时模仿）。≥ 6 条，覆盖各风格维度
- `lexicon.md`：标志词 / 句式模板 / 禁用清单（结合高频字与四字组数据）
- `limits.md`：逐维标注【可模仿 | 部分可模仿 | 难模仿】，诚实标注
- `fingerprint.json`：**分层是标准产出，不分作者**。先用 `build_delta --layered`
  从入库章节自动生成分层阈值 + Delta 档案 + 真迹留一及格线（格式见
  schemas/fingerprint.schema.json，任意作者同构）：
  ```bash
  python scripts/build_delta.py <项目>/corpus/<来源> --pack stylepacks/<包名> --layered
  ```
  脚本产出后人工复核两点：分层归属是否符合直觉（不符合通常是语料脏或
  文体混编，回 1.5 体检）；留一及格线是否标定（层内 n<3 会如实置空，
  说明"该层 Delta 待语料扩充"，不要手拍一个数充数）
- `metrics` 顶层（混合）手填时的参考：句长 P50 取实测值、比例与频率类容差
  **必须来自层内/语料内各篇实测散布**（固定比例容差会被罕见指标的跨篇波动
  击穿，真迹会挂自己的线——v0.2.3 实测教训）；`reference` 保存完整实测快照；
  `notes` 说明统计口径
- `pack.json`：**诚实填写** `corpus`（works / total_chars / sampling / confidence）
  与 `provenance`；样本少就写低置信度，不夸大

### 4. 人工校订（不可跳过）
把草案**逐节**呈给用户确认修改，重点核对：生成指导映射表、禁用清单、limits、
thought.md（立意动作可溯源性与禁区措辞）。
用户确认后：

```bash
python scripts/validate_pack.py stylepacks/<包名>
python scripts/export_pack.py stylepacks/<包名> --out <项目>/style/pinned-pack.md
```

## 纪律
- 引文只收短句（≤200 字）；受版权保护文本只做分析、全文不入仓库；公版作者不受限
- 统计与结论分离：profile 中每个判断尽量能追溯到范例或指标
