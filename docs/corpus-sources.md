# 公版语料源登记表

> 纪律：仓库不自带任何全文；本表只登记**已验证的公版源与抓取食谱**，
> 供 corpus-ingest 接续。每次抓取必须留 provenance（URL + 日期 + commit/版本），
> 多来源交叉验证，单来源需在档案元数据标注置信度。

## 使用流程

1. 从下表选源（主源失败用备选源——维基文库在部分网络环境不可达，勿单点依赖）
2. 抓取到 `downloads/corpus/<作者>/`，同目录写 `<作品>.provenance.json`
3. `corpus-ingest` 入库（编码探测 / 去水印 / --unwrap 合并硬换行 / 拆章）
4. `build_delta.py <语料目录> --pack <包目录> --layered` 重建分层指纹
5. 跑 `evals/cases.md` Case F（真迹过线）确认无回归，再升包版本

## 注意

- **不收录**非公版作者；使用侧合规由使用者自负（见 CONTRIBUTING 版权红线）
- Gutenberg 现代中文文学馆藏近乎为零，别在这上面浪费时间；
  中文公版现代文学的可行来源是维基文库镜像与开源整理仓库（需 commit 固定）
- 抓取脚本属临时工具，不入仓库；仓库只收 provenance 与清洗后的入库产物流程
- 清洗纪律（v0.2.8 固化）：去代码围栏 / 居中署名 / 标题行 / 作者行；
  **编者脚注区整段截断**（①②…、⑴⑵…、注：、按：、■/□ 节头，逐行删会留跨行碎片）；
  正文中的 □ 缺字符（如《药》"古□亭口"）系原刊/原辑录标记，按保持原样原则保留
